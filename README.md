# Housing Prices Prediction

This projet is done in the context of a famous kaggle competition where the goal is to create the best model to predict the price of a house. The dataset input consist of 80 house features (also called predictor in ml), and the output is the price of the house (also called prediction). 
Several data preprocessing have been done seperately, creating different versions of the dataset. This way, we could provide each model an adapted version of the dataset. 
After training and evaluating the performance of our models, we chose for the final kaggle predictions the one that shows the lower error metrics. Then we visualised the error of our model in 3 different ways, giving us insights not only on the general interval of confidence, but also on how the error behaves according to the price of a house.
